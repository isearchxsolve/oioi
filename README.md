# oioi

> Build a true, production-grade clone of oiioii.ai You are taking over the existing `oioi` codebase (React + Vite frontend + FastAPI backend + 7-agent pipeline + free-tier providers). The expo-node scaffold will be generated on autopilot start — augment it, fix errors, add real NIM-powered features, and verify the full stack works.

## Stack
| Layer | Technology |
|-------|-----------|
| Mobile | Expo / React Native |
| Backend | Node.js + Express |
| Database | SQLite (better-sqlite3) |
| Auth | JWT |

## Quick Start
```bash
# Server
cd server && npm install && npm start

# Expo
npm install && npx expo start
```
